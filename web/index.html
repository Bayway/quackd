This is the whole interface the robot has: a twist — three numbers, vx, vy, wz — and a head angle. Two learned policies use them: one stands it up, one walks it. The kick is quackd's own scripted impulse, not a policy. None of it reads English.

There is no key for say, and no key for walk to the person and quack. A key carries a command. A sentence needs something to read it — that is the box above. A verb leaves a line in the log; a twist leaves a number in the readout.

These are for a laptop keyboard. On a phone, use the box above.

03Your API key

The key stays in this tab. It goes straight from your browser to the model you pick, is never stored and never passes through any server of ours. Every call is billed to you. Prefer nothing to leave the machine at all? Pick Local.
